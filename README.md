# 정시 지원 판세도

수능 성적을 **대학별 반영비율로 다시 계산해** 34개 대학 1,539개 모집단위를
위험 · 상향 · 소신 · 적정 · 하향 다섯 칸에 배치하는 단일 페이지 웹앱.

같은 성적이라도 대학마다 유리·불리가 갈린다는 것을 눈에 보이게 만드는 것이 목적이다.
예를 들어 수학 반영비율이 43.3%인 서강대와 20%인 숭실대는 같은 학생을 전혀 다르게 평가하고,
영어 4등급은 건국대에서 −0.5%p, 중앙대에서 −8.0%p의 차이를 만든다.

---

## 기능

### 1. 성적 입력
- **영역**: 국어 · 수학 · 영어 · 탐구 2과목
- **표준점수 / 백분위 / 등급**을 한 줄에서 동시에 입력 (영어는 등급만)
- **선택과목 지정**
  - 국어: 화법과작문 · 언어와매체
  - 수학: 확률과통계 · 미적분 · 기하 — 미적분·기하는 대학별 수학 가산점 적용 대상
  - 탐구: 사회·과학 13과목 — 두 과목 모두 과학탐구이면 대학별 과탐 가산점 적용
- **한쪽만 입력해도 계산** — 표준점수나 백분위 중 하나만 넣으면 빈 쪽은 수능 표준↔백분위 대응 곡선으로
  채워 계산한다 (입력 칸은 비워 둔 채로).
- **탐구 1과목만 입력**해도 입력된 과목 기준으로 계산하고, 그 사실을 입력 패널 머리에 표시한다.
- **예시 성적으로 시작** — 첫 화면부터 결과가 보이도록 예시 성적이 채워진 채로 열린다.
  「예시 성적」 버튼으로 언제든 되돌릴 수 있다.
- **대응표 보정값 표시** — 입력한 성적표가 내장 대응표와 얼마나 어긋나는지(국·수·탐 표준점수 차)를
  입력 패널 머리에 보여준다. 자세한 원리는 아래 「계산 방식」 참조.

### 2. 판세 요약
- 국·수·탐 **평균 백분위**와 **추정 누적 백분위**(근사치)
- 전체 모집단위의 **5단계 분포 막대**와 단계별 학과 수
- **합격선 기준 전환** — 최신 학년도 / 학년도 평균(2023~2026 중 결과가 있는 해)

### 3. 5단계 경계 조절
- 하향 · 적정 · 소신 · 상향이 시작되는 격차(%p)를 **슬라이더로 직접 조절** (−6 ~ +6%p, 0.1 단위)
- 경계 순서(하향 ≥ 적정 ≥ 소신 ≥ 상향)는 자동으로 유지되고, 「기본값」으로 복원 가능

| 단계 | 기본 경계 (합격선 대비) | 의미 |
|---|---|---|
| 하향 | +1.5%p 이상 | 여유 있게 넘어서는 안전 구간 |
| 적정 | +0.4 ~ +1.5%p | 합격선을 안정적으로 넘는 주력 구간 |
| 소신 | −0.7 ~ +0.4%p | 합격선 근처. 경쟁률·이월에 따라 갈리는 구간 |
| 상향 | −2.2 ~ −0.7%p | 한 장 걸어볼 만한 도전 구간 |
| 위험 | −2.2%p 미만 | 합격선과 차이가 커서 사실상 어려운 구간 |

### 4. 5단계 보드
- 다섯 개 열에 학과 카드를 격차 순으로 배치
- 카드마다 모집군, 대학·학과명, **합격확률 게이지**, 합격선 대비 **격차(%p)** 표시
- 합격선이나 반영비율 중 하나라도 추정치인 학과에는 `추정` 배지가 붙는다
- 색만으로 의미를 전달하지 않도록 단계 이름이 항상 함께 표시된다

### 5. 필터·검색
- **계열**: 전체 / 인문 / 자연 / 의약
- **모집군**: 전 군 / 가군 / 나군 / 다군
- **검색**: 대학명 · 학과명 · 지역명(예: `부산`, `경기`)
- **관심권만**: 합격선 ±6%p 안의 학과만 표시 (기본 켜짐)

### 6. 학과 상세 시트
카드를 누르면 열린다.
- **판정 요약** — 단계, 내 환산총점 vs 합격선 환산총점, 격차, 합격확률
- **학년도별 합격선** — 2023~2026학년도 70% 컷 평균백분위, 그 해 70% 컷 수험생의 영어 등급, 최근 경쟁률·모집인원
- **컷 대비 위치** — −6 ~ +6%p 눈금 위의 내 위치
- **영역별 반영비율** — 스택 막대, 영어 반영 방식(비율 포함형 / 총점 가·감점형)과 등급별 환산값,
  수학·과탐 가산율
- **영역별 취득 점수** — 1000점 만점 기준으로 영역마다 내 점수 막대와 합격선 수험생 점수 눈금(▼)을 비교
- **반영비율 직접 수정** — 모집요강 원문과 다르면 고쳐서 바로 재계산. 합계가 100이어야 적용되고,
  「원래대로」로 되돌릴 수 있다. 영어 감점형 대학은 영어 칸이 잠긴다(영어 배점이 증발하는 것을 막기 위해).

### 7. 원서 3장 트레이
- 상세 시트에서 「○군에 담기」 → 가·나·다군 **각 1장**씩 담는다 (정시 지원 규칙 그대로)
- 담은 학과는 성적·경계값을 바꾸면 단계·격차·확률이 실시간으로 갱신된다

### 8. 기타
- **라이트 / 다크 테마** 전환 (기본은 시스템 설정을 따름)
- **모바일 대응** (400px 폭까지)
- **자동 저장** — 성적, 경계값, 반영비율 수정, 담아둔 원서가 브라우저(localStorage)에 저장된다.
  저장이 막힌 환경에서도 앱은 그대로 동작한다.
- **면책 배너와 「계산 방법」 푸터** — 이 도구가 무엇을 근사하는지 페이지 안에서 밝힌다.

## 계산 방식

```
성적 입력
  ↓ ① 영역 정규화 — 표준점수 반영 대학: 취득 표준점수 ÷ 만점 표준점수 / 백분위 반영 대학: 백분위
  ↓ ② 대응표 보정 — 합격선(백분위)을 표준점수로 바꿀 때, 대응 곡선을 내 성적표가 지나는 점에 맞춰 평행이동
  ↓ ③ 환산총점 = Σ(정규화값 × 반영비율) ÷ 10   (1000점 만점)
  ↓    + 영어 (비율 포함형은 비율 안에서, 감점형은 총점에서 가·감점)
  ↓    + 미적분·기하 / 과탐 가산
  ↓ ④ 격차 = (내 환산총점 − 합격선 환산총점) ÷ 10   [단위: %p]
  ↓ ⑤ 5단계 분류 + 로지스틱 합격확률
```

합격선 환산총점은 **국·수·탐이 모두 합격선 백분위이고, 영어는 그 학과 70% 컷 수험생의 실제 등급인
가상 수험생**으로 계산하며, 가산점은 적용하지 않는다. 영어 등급은 「어디가」가 2026학년도에만 공개해
두 합격선 기준 모두 그 값을 쓰고, 자료가 없는 7개 학과만 1등급으로 가정한다.

②의 보정이 없으면 표준점수와 백분위가 대응표와 어긋나는 성적표(실제로 흔하다)를 가진 학생이
표준점수형 대학과 백분위형 대학에서 서로 다른 잣대로 평가된다.

## 데이터

- **34개 대학 / 1,539개 모집단위** — 서울 주요 대학, 수도권, 지방 거점국립대, 교육대학
  (인문 692 · 자연 795 · 의약 52, 예체능·특별전형 제외)
- **합격선**: 대교협 대입정보포털 [「어디가」](https://www.adiga.kr) 정시 일반전형 결과,
  **최종등록자 70% 컷의 국·수·탐 평균백분위**, 2023~2026학년도.
  `scripts/fetch-adiga.js`로 원자료를 받아 `data/adiga/raw/`에 두고, `scripts/import-adiga.js`가 `src/univs.js`를 만든다.
- **반영비율**: 프로필 69종 (대학별 인문/자연, 표준점수/백분위 반영, 영어 환산표, 가산율).
  공개 보도자료를 정리한 **참고값**이며 1,539개 중 409개만 출처로 확인됐다.
  반영비율이나 합격선이 추정치이면 `추정` 배지가 붙고, 상세 시트에서 어느 쪽인지 표시된다.

## 알려진 한계

- 반영비율의 상당수가 **추정치**이고, 한 대학 안에서는 계열별로 같은 비율을 쓴다.
- 여러 학년도 합격선이 있는 모집단위는 668개다. 2024·2025학년도는 평균백분위를 공개하지 않은 대학이 많다.
- 계열(인문/자연)은 모집단위명으로 분류해 틀릴 수 있다. 가천대는 백분위 합격선을 공개하지 않아 빠졌다.
- 합격선은 연도별 변동이 크고, 모집인원이 적은 학과일수록 오차가 크다.
- 표준↔백분위 대응표는 실제 수능 분포의 **근사**다. 보정을 거쳐도 완전하지 않다.
- 합격선 수험생의 영어 등급은 70번째 등록자 한 명의 값이라 학과마다 들쭉날쭉할 수 있다.
- 합격확률은 격차를 로지스틱 곡선에 넣은 **참고 수치**다. 경쟁률, 추가합격 이월, 군별 연쇄이동,
  수능 최저학력기준, 학생부 반영은 계산하지 않는다.
- 예체능·특수전형·지역인재·논술은 범위 밖이다.

## 실행

```bash
npm test          # 데이터 불변식 11종 + 엔진 42종 + 시뮬레이터 18종 = 71개
npm run sim       # 가상 수험생 30만 명 모의 지원 → 경쟁률 예측 (sim/README.md)
node sim/apply.js --kor 95 --math 96 --tam 96,94 --eng 2 --pick "서강대 컴퓨터"   # 수험생 모의 지원
npm run build     # dist/index.html 생성 (+ 게시 규칙 검증)
npm run check     # 둘 다
```

의존성 없음. `node`만 있으면 된다. 빌드 결과 `dist/preview.html`을 브라우저로 열면 확인할 수 있다.

## 구조

```
src/data.js      반영비율 프로필
src/univs.js     대학·모집단위·학년도별 합격선 (자동 생성)
src/engine.js    환산점수·5단계 판정 엔진
src/app.html     UI (빌드가 데이터·엔진을 끼워 넣는다)
scripts/build.js src/* → dist/index.html 단일 파일
scripts/fetch-adiga.js / import-adiga.js   「어디가」 원자료 수집 · 변환
data/adiga/raw/  「어디가」 원자료
sim/             모의 지원 시뮬레이터 — 경쟁률 예측·수험생 모의 지원 (앱과 분리, 결과는 sim/out/)
tests/           데이터 불변식 · 엔진 검증 (의존성 없는 자체 하네스)
```

`scripts/build.js`가 세 파일을 문자열 치환으로 합쳐 `dist/index.html` 한 장을 만든다.
테스트는 `tests/_load.js`가 **빌드와 같은 순서로** data와 engine을 합쳐 평가하므로,
검증하는 코드와 페이지에 실리는 코드가 동일하다.

작업 규칙·데이터 규칙·엔진 불변식은 [CLAUDE.md](./CLAUDE.md)에 있다.

> 이 도구는 진학 상담을 대체하지 않는다. 판단의 출발점이지 결론이 아니다.
> 실제 지원 전에는 각 대학 모집요강 원문을 확인할 것.
